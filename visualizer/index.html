AXI-Lite Interface

The host sends AW, W and AR requests to the register block and receives B and R responses back, including SLVERR for bad accesses.

Transmit Path

Software writes TXDATA, the register block pushes the byte into the TX FIFO, and UART TX pops it and serializes it onto TXD.

Receive Path

UART RX synchronizes and samples RXD, then pushes the byte with its parity and framing flags into the RX FIFO. Reading RXDATA pops it.

Control

Baud divisor, parity, stop bits and the TX/RX enables flow from the registers to UART TX and UART RX. Flush and pop commands go to the FIFOs.

Status and Events

FIFO full and level, busy and done flags, and parity, framing and overrun events flow back into STATUS, LEVEL and IRQ_STATUS.

Clock and Reset

One clock and one active-low reset feed every block, so the whole design is a single clock domain.
